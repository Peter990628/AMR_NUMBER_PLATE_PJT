# 이상치 제외 후 EMA 기준 갱신 실험

2026-11-12 저장 데이터 재생과 합성 입력 실험이다. **EMA 방식은 후보 출력 끊김을 줄였지만, 개선의 상당 부분은 ‘거절한 값으로 정상 기준을 덮어쓰지 않는 것’에서 나왔다.** 먼저 마지막 채택값을 기준으로 유지하는 단순한 방식을 실제 장면에서 검증하는 것이 적절하다. 이번 작업은 오프라인 도구이며 운영 노드·설정·USD에는 적용하지 않았다.

## 시험한 변경

기존 RANSAC/PCA(cap20), min/max 끝점, 후보 생성식을 그대로 사용한다. 관측 시각의 정확한 TF로 후보 위치·목표점·yaw를 odom으로 변환한 뒤 판정한다. A/B는 위치 거리 합이 작은 대응으로 맞춘다.

기존 판정기는 현재 후보를 최대 3개의 이전 관측 각각과 비교한다. 하나라도 15cm 또는 3°를 넘으면 이력을 비우고 **방금 거절한 관측을 새 이력의 시작으로 넣는다.** 따라서 원래 위치로 복귀해도 그 이상 관측과의 차이 때문에 다시 거절될 수 있다.

새 시험기는 다음과 같이 동작한다.

1. 처음에는 서로 일치하는 관측 3개로 기준을 확인한다.
2. 새 후보의 위치·목표점·yaw를 **갱신 전 기준**과 비교한다. 위치는 XYZ 전체에서 15cm, yaw는 각도 경계를 고려한 3° 조건이다.
3. 통과하면 현재 후보를 채택하고 기준을 `0.8 × 이전 기준 + 0.2 × 새 값`으로 갱신한다. yaw는 가장 짧은 각도 차이를 적용한다.
4. 벗어나면 현재 출력은 무효로 내고 내부의 정상 기준은 잠시 유지한다. 다음 관측이 정상 범위로 돌아오면 즉시 채택한다.
5. 다른 위치가 서로 일치하는 관측 3회로 계속 나타나면 별도 확인 이력으로 새 기준을 만든다. 이 규칙은 실제 변화에 대응하기 위한 것이다.
6. 입력 무효·잘못된 시각·좌표계/세션 변경·0.35초 초과 입력 간격·1초 wall-time 입력 중단은 초기화한다. 거절이 계속될 때도 마지막 채택으로부터 source time 0.35초가 넘으면 이전 기준을 폐기한다.

**EMA는 내부 비교 기준에만 사용한다.** 채택된 출력은 그 시각의 원래 후보 기하를 그대로 사용하며, 무효일 때 이전 후보를 유효 출력으로 재발행하지 않는다. 평균낸 위치·목표점이 원래의 이격 거리/방향 조건을 만족한다고 가정하지 않는다. 입력 중단 검사는 도구의 `expire()` 호출로 검사하며 실제 ROS 타이머 동작을 시험한 것은 아니다.

비교군으로 alpha=1도 실행했다. 이것은 평균을 내지 않고 **마지막 채택 관측을 기준으로 유지**하는 방식이다. 거절값으로 기준을 덮어쓰지 않는 규칙과 3회 재확인 규칙은 EMA 방식과 같다. alpha=0.1/0.4는 민감도 확인용이며 기본값을 최적화했다고 주장하지 않는다.

15cm·3°라는 숫자는 같지만 ‘이전 관측 각각’과 비교하는 것과 ‘한 기준’에 비교하는 것은 서로 다른 조건이다. 예를 들어 평균 양쪽에 있는 −10cm와 +10cm 관측은 각각 기준을 통과해도 서로는 20cm 차이가 난다.

## 저장 데이터 결과

| 저장 장면 | 기존 판정 | EMA 기준(alpha=0.2) | 마지막 채택값 유지(alpha=1) |
|---|---:|---:|---:|
| 주 데이터 | 90/118 (76.3%) | 114/118 (96.6%) | 110/118 (93.2%) |
| 평행 복귀 | 83/87 | 87/87 | 87/87 |
| +10° | 82/89 | 88/89 | 85/89 |
| −10° | 78/85 | 84/85 | 83/85 |

채택률은 **후보를 사용할 수 있었던 비율**이다. 차량 실제 끝점의 정답이 없으므로 정확도라고 해석하면 안 된다. 총 389개 대응 스캔을 실제 C++로 다시 피팅했으며, 비교 구간은 379개다.

주 데이터의 첫 기록은 TF와 이전 판정 이력이 없어 122개 전체를 같은 초기 상태에서 완전히 재현할 수 없다. 모든 방법을 index3에서 빈 상태로 시작하고 index4~121의 동일한 118개를 비교했다. 기존 방식의 이 118개 상태는 실제 기록과 전부 일치했다. 다른 세 장면은 index0에서 초기화하고 index2 이후를 집계했다. 당시 cap10 기록의 유효 기하는 동일함을 확인했지만, 이번 모든 비교는 cap20이므로 당시 무효 판정까지 그대로 복원하는 실험은 아니다.

약 1.5m 튄 두 부분 소실 관측(index16,115)은 EMA와 마지막 채택값 유지 방식 모두 거절했다. 다음 정상 관측(index17,116)에서 바로 복귀했다. 기존 방식은 index20,118에서 복귀했다. 소실 관측으로부터 복귀까지 source time은 기존 약 0.4/0.3초, 두 새 방식은 약 0.1초였다. 소실 인덱스는 결과 표시에만 쓰며 알고리즘에 정답으로 주지 않았다.

주 데이터 EMA의 무효 4개는 초기 확인 1개와 거절 3개(index16,38,115)다. 저장 데이터 전체에서 새 기준 재획득은 발생하지 않았다. 재획득 기능의 근거는 아래 합성 실험이다.

## 출력 흔들림은 별도 평가

| 주 데이터 연속 채택 출력의 위치 변화 | 기존 | EMA 0.2 | 마지막 채택값 유지 |
|---|---:|---:|---:|
| 비교한 연속 쌍 수 | 79 | 110 | 103 |
| p95 | 12.22cm | 14.17cm | 12.22cm |
| 최대 | 14.98cm | 18.90cm | 14.98cm |
| 15cm 초과 | 0 | 3 | 0 |

각 방식이 채택한 연속 쌍의 수가 다르다. 같은 시각을 두 방식이 모두 채택했을 때 출력 기하는 완전히 동일하다. EMA의 내부 기준 변화 p95는 약 2.12cm지만 **이것은 출력 위치의 흔들림 감소가 아니다.**

네 장면 전체에서 EMA는 마지막 채택값 유지보다 8개 관측을 더 채택했으며, 연속 채택 출력이 15cm 넘게 바뀐 경우는 6쌍이었다. 마지막 채택값 유지 방식은 해당 초과가 없었다. 따라서 채택률 상승 전체를 EMA 평균화 효과로 설명해서는 안 된다. alpha=0.1/0.2/0.4의 채택 개수는 이 짧은 저장 자료에서 같았으며, 최적 alpha를 정할 근거는 부족하다.

보고서는 연속 두 입력을 모두 채택한 쌍과, 중간 무효를 건너뛴 다음 채택 출력 쌍을 구분한다. 후자는 0.35초 이내 쌍과 간격 제한 없는 쌍도 각각 기록한다. 서로 다른 세션·프레임·후보 설정 사이의 이동량은 비교하지 않는다.

## 합성 입력으로 확인한 한계

10Hz에서 20회 안정 입력 후 변화 구간 50회를 평가했다. 아래 속도는 **odom에서 관측 후보 자체가 이동하는 속도**다. 정지 차량 옆에서 AMR만 움직이는 주행 속도와 같지 않다.

| 합성 상황 | 기존 | EMA 0.2 | 마지막 채택값 유지 |
|---|---:|---:|---:|
| 한 번만 끝점 1.5m 축소 후 복귀 | 47/50 | 49/50 | 49/50 |
| 계속 끝점 1.5m 축소 | 48/50 | 48/50 | 48/50 |
| 후보 전체가 0.3m 이동한 뒤 유지 | 48/50 | 48/50 | 48/50 |
| 후보가 0.1m/s로 계속 이동 | 50/50 | 50/50 | 50/50 |
| 후보가 0.4m/s로 계속 이동 | 50/50 | 36/50 | 50/50 |
| 위치가 ±10cm로 번갈아 흔들림 | 1/50 | 50/50 | 25/50 |

EMA는 0.4m/s 변화에서 기준이 뒤처져 정상 이동도 거절했다. ±10cm 입력에서는 매번 통과했지만 현재값 출력이므로 20cm씩 움직였다. 마지막 채택값 유지 방식은 평균 지연이 없고, 반복 흔들림의 반대편 관측을 거절했다.

**지속적인 부분 소실과 실제 위치 변화를 이 필터만으로 구분할 수 없다.** 둘 다 일관된 관측 3개가 되면 약 0.2초 후 새 기준으로 받아들였다. 실제 차량 끝점인지 또는 관측 구간이 잘린 것인지 확인하려면 별도의 관측 품질 정보가 필요하다. 이 결과는 합성 기하 검증이며 실제 주행이나 장면에서의 동적 검증을 대신하지 않는다.

단위 테스트 19개는 이상치 후 복귀, 거절값의 기준 오염 방지, 3회 재확인, 시각 역행/중복, 입력 간격, 기준 유효기간, 입력 중단, 좌표계 변경, A/B 교환, ±π 각도 경계와 입력 검증을 검사한다. 합성 시나리오는 14종이며 기존 C++ 판정기와 두 새 방식으로 비교한다. 0.5m/s 추가 시나리오는 기존 15cm 경계에 정확히 걸려 부동소수점 영향이 있으므로 위 결론은 경계를 피한 0.4m/s 결과를 사용했다.

## 재현과 파일

```bash
cd ~/peter_pjt
python3 tools/test_candidate_ema_experiment.py
python3 tools/evaluate_candidate_ema.py \
  --output-dir local_artifacts/ema_trial01
python3 tools/probe_candidate_ema_dynamics.py \
  --baseline-binary local_artifacts/ema_trial01/replay \
  --output-dir local_artifacts/ema_trial01_dynamics
```

첫 평가기는 새 출력 디렉터리를 요구한다. 현재 프로젝트의 네 로컬 캡처를 기본 입력으로 사용하며 `--artifact-root`로 캡처 상위 경로를 지정할 수 있다. ROS나 Isaac Sim 실행은 필요하지 않다. C++17 컴파일러와 Eigen 헤더, Python 표준 라이브러리를 사용한다.

- `tools/candidate_ema_experiment.py`: 순수 Python 실험 판정기.
- `tools/test_candidate_ema_experiment.py`: 상태 전환과 실패 입력 단위 테스트.
- `tools/evaluate_candidate_ema.py`: 실제 C++ 피팅·기존 판정기와 같은 입력으로 비교.
- `tools/probe_candidate_ema_dynamics.py`: 변화·소실·시간 이상 합성 실험.

최종 저장 자료는 Git에서 제외된 `local_artifacts/ema_gate_experiment_2026-11-12/final/`이다. `report.json`에 설정·집계·입력/코드 해시가 있으며 각 장면의 JSONL에는 원래 피팅, 입력 식별자, 판정, 내부 기준, 현재 출력이 기록된다. 합성 최종 결과는 `dynamics_final/report.json`과 시나리오별 JSONL이다. `run01`은 초기 평가기에서 tuple/list 동일성 검사에 걸린 미완료 실행이며, `run02`는 간격 제한 없는 출력 비교 항목을 추가하기 전 결과다. 최종 결론에는 `final`을 사용한다.

Python 판정 호출 1,930회의 오프라인 측정은 평균 약 0.043ms, p95 약 0.063ms였다. 복사·검증을 포함한 판정 부분만의 호스트 시간이고 피팅·TF·ROS 통신·타이머 및 운영 C++ 노드 지연은 포함하지 않는다.

현재 권고는 **기존 끝점 계산을 유지하고, 마지막 채택값을 기준으로 보존하는 방식부터 실제 장면에서 검증**하는 것이다. EMA를 출력 자체에 적용하는 작업은 이격 거리·방향 기하와 이동 지연을 별도로 확인해야 하며 이번 실험에 포함하지 않았다.
